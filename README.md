### 这是什么

一个单文件的清单工具。分卷、打勾（御印）、整卷全批、查档、批量录入、存档/呈进。

- **纯本地**：你写的内容只存在你自己的浏览器里，不上传任何地方。这个仓库里只有程序本身。
- **离线可用**：第一次打开后就缓存在设备上，飞行模式照样开。
- **零依赖**：一个 HTML 文件，不引用任何外部资源。

### 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 全部程序，双击也能直接用 |
| `sw.js` | 离线缓存。改了程序要把里面的 `VERSION` 加一 |
| `manifest.json` | 加到主屏幕时的名字和图标 |
| `icon-*.png` | 图标，`make_icon.py` 生成 |

### 换新版本

网页上直接改就行，不用装任何东西：

1. 点开 `index.html` → 右上角铅笔 **Edit** → 改 → 底下 **Commit changes**
2. 顺手把 `sw.js` 里的 `VERSION` 改成下一个（`v2` → `v3`），否则设备上还是旧缓存
3. 等一两分钟，手机上打开会提示「新版已到」，点「换上」

或者 **Add file → Upload files**，把新的 `index.html` 拖进去覆盖。

### 国库与六部

批一件入库二両，整卷办结再赏十両——**这是底数，实得几両看朝纲**。库银在**内库**（菜单 → 内库）里换御印和折纸。

| 朝纲（六部均分） | 倍率 | 每件 | 这一档还给什么 |
|---|---|---|---|
| 朝纲不振 <40 | ×0.5 | 1 両 | —— |
| 隐忧渐生 40 | ×1 | 2 両 | —— |
| 四海承平 55 | ×1.5 | 3 両 | 整卷 15 両 |
| 政通人和 70 | ×2 | 4 両 | 解锁**金云笺** · 荒疏五日才起（平时三日） |
| 海晏河清 85 | ×3 | 6 両 | 解锁**玉玺** · 四角描金 · 换一句副题 |

倍率只乘底数，勤政加赏和治绩赏格不乘。入库当时是几両就记几両，撤回照那个数退——
朝纲后来涨跌，都不动已经入过库的账。**恩典之物（玉玺、金云笺）银子够也得朝纲够**，
跌下去自动换回原来的，东西还在，不用再买。

每一卷可以派给**六部**之一（改卷时选）。批那一卷的折子，对应部的**办事效率**和**忠诚度**就涨；
一个部三天没差事办就开始荒疏，效率、人心一并往下掉，跌到二十五为止。
六部均分即**朝纲**，八十五以上是海晏河清。

库银也能花在人身上：**赏赐**四十両换忠诚度，**申饬**换效率但伤人心——压不到底限以下。

**治绩**十件，难的赏得多（5 ~ 50 両，合计 240 両），牌子上标着各值多少。
铺子里全套要 720 両，光靠治绩买不完。

花银子（买印章纸色、赏赐）和动刀子（撤卷、焚书、重开一局、断驿传）都要**过一道确认**，
手滑点到不至于当场破财。买过的东西换来换去不花钱，换的时候不问。

撤勾、删件、撤卷、焚书，都会把那些折子挣来的库银和部里的功劳**照数退回**；
国库不够退就挂**亏空**，往后入库先抵亏空。所以「批完花光再撤回」「建卷全批再删卷」都刷不出银子。

### 两处同步（驿传）

菜单 → **驿传**，填自己的一个**私有**仓库、文件名、和一个只给 `Contents: Read and write` 的
fine-grained token，手机和电脑就读写同一份 json。

- 合并规则：**任一边批过的勾都留着**；事由和朱批按改动时刻取新的；**删条目不同步**（要删就两台都删）
- 令牌只存在本机 localStorage，**不写进存档文件**，也不发去别处
- 不接驿传就跟以前一样，纯本地，什么都不外传
